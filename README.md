# IPv6 Address Types Lab

This project demonstrates an **IPv6 network configuration using Cisco Packet Tracer**. The lab includes two routers, two switches, and five PCs with IPv6 addressing, prefix lengths, default gateways, and static routing.

**Network Components:**

* 2 Routers: R1 and R2
* 2 Switches: SW0 and SW1
* 5 PCs distributed across two LANs
* IPv6 Global Unicast addressing
* `/64` IPv6 prefix length
* R1–R2 IPv6 transit network
* Static IPv6 routing
* IPv6 connectivity testing using `ping`

**IPv6 Networks:**

* R1 LAN: `2001:DB8:ACAD:1::/64`
* R2 LAN: `2001:DB8:ACAD:2::/64`
* R1–R2 Transit: `2001:DB8:ACAD:10::/64`

**Purpose:**

To demonstrate IPv6 address configuration, prefix length, router-to-router connectivity, static IPv6 routing, and end-to-end communication between different IPv6 networks using Cisco Packet Tracer.
